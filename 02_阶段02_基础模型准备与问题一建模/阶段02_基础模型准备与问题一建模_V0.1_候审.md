\[
\theta_j\in[0,2\pi),\qquad
\vec u(\theta_j)=(\cos\theta_j,\sin\theta_j,0).

\[
\mathcal T=\{(x,y,z):x^2+(y-200)^2\le7^2,\ 0\le z\le10\}.

烟幕有效球半径

\[
R_S=10\ \mathrm m,

\[
v_S=3\ \mathrm{m/s},

单个云团有效时间

\[
T_S=20\ \mathrm s.
\]

重力加速度主计算先取 \(g=9.8\ \mathrm{m/s^2}\)，后续以 9.81 做敏感性复核。

## 2. 公共运动学

### 2.1 导弹

导弹 \(i\) 初始位置为 \(\vec M_i^0\)，以 \(v_M=300\ \mathrm{m/s}\) 直指原点：

\[
\boxed{
\vec M_i(t)=
\vec M_i^0-
300t\frac{\vec M_i^0}{\|\vec M_i^0\|}
},
\qquad
0\le t\le T_i,
\]

\[
\boxed{
T_i=\frac{\|\vec M_i^0\|}{300}.
}
\]

### 2.2 无人机

无人机 \(j\) 受领任务后瞬时选定水平航向 \(\theta_j\) 与速度 \(v_j\)，之后不再调整：

\[
\boxed{
\vec F_j(t)=\vec F_j^0+v_jt\vec u(\theta_j)
},
\qquad 70\le v_j\le140.
\]

### 2.3 烟幕弹

第 \(j\) 架无人机第 \(k\) 枚烟幕弹在 \(t_{jk}^d\) 投放，引信延迟 \(\tau_{jk}\)，起爆时刻

\[
t_{jk}^e=t_{jk}^d+\tau_{jk}.
\]

烟幕弹脱离时继承载机水平速度，竖直初速度为 0。令 \(s=t-t_{jk}^d\)，则投放至起爆阶段

\[
\boxed{
\vec P_{jk}(t)=
\vec F_j(t_{jk}^d)
+v_js\vec u(\theta_j)
-\frac12gs^2\vec e_z
}.
\]

投放点

\[
\boxed{
\vec P_{jk}^d=
\vec F_j^0+v_jt_{jk}^d\vec u(\theta_j)
}
\]

起爆点

\[
\boxed{
\vec P_{jk}^e=
\vec F_j^0+v_jt_{jk}^e\vec u(\theta_j)
-\frac12g\tau_{jk}^2\vec e_z
}.
\]

因此投放点、起爆点不是独立自由变量。起爆高度要求

\[
z_{jk}^e=z_j^0-\frac12g\tau_{jk}^2\ge0,
\]

故

\[
\boxed{
0\le\tau_{jk}\le\sqrt{\frac{2z_j^0}{g}}.
}
\]

### 2.4 云团

对

\[
t\in[t_{jk}^e,t_{jk}^e+20]
\]

有

\[
\boxed{
\vec C_{jk}(t)=
\vec P_{jk}^e-3(t-t_{jk}^e)\vec e_z.
}
\]

凡 \(0\le z_{jk}^e<10\) 的低空起爆策略，后续必须进入地面边界敏感性检验。

## 3. 单个目标点的精确线段判据

给定导弹位置 \(\vec M\)、烟幕中心 \(\vec C\)、目标点 \(\vec P\)，真实视路是闭线段

\[
[\vec M,\vec P]=\{\vec M+\lambda(\vec P-\vec M):0\le\lambda\le1\}.
\]

令

\[
\vec a=\vec P-\vec M,\qquad
\vec b=\vec C-\vec M.
\]

烟幕中心到该线段最近点的参数为

\[
\boxed{
\lambda^*=\operatorname{clip}\left(
\frac{\vec a\cdot\vec b}{\|\vec a\|^2},0,1
\right).
}
\]

于是

\[
\boxed{
d(\vec C,[\vec M,\vec P])=
\|\vec b-\lambda^*\vec a\|.
}
\]

目标点被遮挡当且仅当

\[
\boxed{
d(\vec C,[\vec M,\vec P])\le R_S.
}
\]

该公式使用线段而非无限直线，可自动排除烟幕在目标后方或导弹后方产生的伪遮蔽。

---

## 4. 全目标遮蔽主口径

主模型采用“全目标遮蔽”定义：在时刻 \(t\)，若导弹通向真目标全部可见方向的视路均被烟幕截断，则判为有效遮蔽。数学上写为

\[
\boxed{
\forall\vec P\in\mathcal T,\qquad
d(\vec C(t),[\vec M(t),\vec P])\le R_S.
}
\]

目标中心点模型只能作为基线，因为“中心视路被遮”不能推出圆柱边缘均被遮。

### 命题 1：遮蔽域为凸集

定义

\[
\mathcal K=\{\vec P:[\vec M,\vec P]\cap\mathcal B(\vec C,R_S)\neq\varnothing\}.
\]

若 \(\vec M\in\mathcal B\)，则 \(\mathcal K=\mathbb R^3\)。

若 \(\vec M\notin\mathcal B\)，则

\[
\mathcal K=
\{\vec M+\lambda(\vec Q-\vec M):\vec Q\in\mathcal B,\lambda\ge1\}.
\]

对任意两点

\[
\vec P_r=\vec M+\lambda_r(\vec Q_r-\vec M),\quad r=1,2,
\]

取 \(\alpha\in[0,1]\)，令

\[
\lambda=\alpha\lambda_1+(1-\alpha)\lambda_2\ge1,
\]

\[
\vec Q=\frac{\alpha\lambda_1\vec Q_1+(1-\alpha)\lambda_2\vec Q_2}{\lambda}.
\]

因球为凸集，\(\vec Q\in\mathcal B\)，从而 \(\alpha\vec P_1+(1-\alpha)\vec P_2\in\mathcal K\)。故

\[
\boxed{\mathcal K\text{ 为凸集}.}
\]

### 命题 2：有限圆柱可严格降为上下两个轮廓圆

定义

\[
\Gamma_h(\varphi)=
(7\cos\varphi,\ 200+7\sin\varphi,\ h),
\]

其中 \(h\in\{0,10\}\)，\(0\le\varphi<2\pi\)。

实心圆柱满足

\[
\boxed{
\mathcal T=\operatorname{conv}(\Gamma_0\cup\Gamma_{10}).
}
\]

因为 \(\mathcal K\) 为凸集，故

\[
\boxed{
\mathcal T\subseteq\mathcal K
\iff
\Gamma_0\cup\Gamma_{10}\subseteq\mathcal K.
}
\]

因此三维连续目标可严格降为两个一维周期极值问题；当前不把它进一步偷换成“只检查四个固定点”。

## 5. 主评价函数

定义

\[
d_h(\varphi,t)=
d\left(\vec C(t),[\vec M(t),\Gamma_h(\varphi)]\right),
\]

\[
\boxed{
D(t)=\max_{h\in\{0,10\},\ 0\le\varphi<2\pi}d_h(\varphi,t),
}
\]

\[
\boxed{
G(t)=D(t)-10.
}
\]

则

\[
\boxed{
G(t)\le0
\iff
\text{有限圆柱目标在时刻 }t\text{ 被该烟幕完全遮蔽}.
}
\]

## 6. 独立复核：射线—球判据

令

\[
\vec r=\vec C-\vec M,\qquad
\vec q=\vec P-\vec M,
\]

\[
D=\|\vec r\|,\qquad L=\|\vec q\|.
\]

若 \(D\le10\)，导弹位于烟幕球内，视路必然被遮。

对 \(D>10\)，定义

\[
\alpha=\arcsin\frac{10}{D},
\]

\[
\beta=\arccos\frac{\vec r\cdot\vec q}{DL}.
\]

目标射线穿过烟幕球要求

\[
\beta\le\alpha.
\]

最近交点的射线距离为

\[
\boxed{
s_-=D\cos\beta-
\sqrt{10^2-D^2\sin^2\beta}.
}
\]

实际线段还需满足

\[
L\ge s_-.
\]

故

\[
\boxed{
[\vec M,\vec P]\cap\mathcal B\neq\varnothing
\iff
\begin{cases}
\beta\le\alpha,\\
L\ge s_-.
\end{cases}
}
\]

该评价器与线段距离评价器独立，用于后续交叉验证。

## 7. 八类强制几何反例

正式代码求解前必须验证：完全遮蔽、完全不遮蔽、中心被遮但边缘可见、最坏视路恰相切、烟幕在目标后方、烟幕在导弹后方、导弹在烟幕内部、烟幕与圆柱局部相交但未遮住全部目标方向。

点目标基线必须在“中心被遮但边缘可见”的反例中主动失败。

## 8. Q5 目标入口裁决

官方 `result3.xlsx` 每一枚烟幕弹均有“有效干扰时长”和单数“干扰的导弹编号”字段。阶段 02 主口径冻结为

\[
\boxed{
J_5=H_1+H_2+H_3\to\max,
}
\]

其中每个 \(H_i\) 都是该导弹对应多枚烟幕有效区间的时间并集长度。

“分别报告、不聚合”只是输出方式，不足以定义优化目标；“三枚导弹同时遮蔽交集”保留为补充指标，不作为主目标。每枚正式使用的烟幕弹指定唯一计划干扰导弹，偶然对其他导弹产生的遮蔽可报告但不重复记入主目标。Q5 后续还要求三枚导弹均进入任务分配集合。

# 10. 问题一遮蔽模型

定义

\[
D_1(t)=
\max_{h\in\{0,10\},\varphi\in[0,2\pi)}
d\left(
\vec C_1(t),
[\vec M_1(t),\Gamma_h(\varphi)]
\right),
\]

\[
\boxed{G_1(t)=D_1(t)-10.}
\]

瞬时遮蔽函数

\[
\boxed{
I_1(t)=
\begin{cases}
1,&G_1(t)\le0,\\
0,&G_1(t)>0.
\end{cases}
}
\]

问题一最终要求的有效遮蔽时长为

\[
\boxed{
H_1=
\int_{5.1}^{25.1}I_1(t)\,dt
=
\mu\{t\in[5.1,25.1]:G_1(t)\le0\}.
}
\]

该表达天然允许 0 个、1 个或多个不连续有效区间，不能先验假设只有一个连续区间。

### 命题 3：\(G_1(t)\) 连续

对固定 \(h,\varphi\)，\(d_h(\varphi,t)\) 由连续轨迹、点积、范数与闭区间投影组成，关于 \(t\) 连续。参数集 \(\{0,10\}\times[0,2\pi]\) 紧，因此连续函数的参数最大值 \(D_1(t)\) 连续，从而

\[
\boxed{G_1(t)\text{ 在 }[5.1,25.1]\text{ 上连续}.}
\]

有效区间边界因此可由 \(G_1(t)=0\) 的根确定。

# 11. 问题一求解步骤（只设计，不运行）

1. 用解析式生成 \(\vec M_1(t)\) 与 \(\vec C_1(t)\)。
2. 对每个时刻，在上下两个轮廓圆上求 \(d_h(\varphi,t)\) 的全局最大值。
3. 用射线—球判据独立复核同一几何判断。
4. 在 \([5.1,25.1]\) 上做确定性粗扫描，定位 \(G_1(t)\) 的符号变化与近零局部极值。
5. 对候选边界使用 Brent 法、二分法或等价一维根搜索精化 \(G_1(t)=0\)。
6. 构造全部 \(G_1(t)\le0\) 区间并取总长度。
7. 对时间步长、圆周初始角度划分密度、极值/求根容差做至少三档收敛检查。

问题一没有优化变量，绝无必要使用 PSO、GA、DE 等群智能算法。
