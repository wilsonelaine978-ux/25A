# 2025 高教社杯全国大学生数学建模竞赛 A 题重做项目

> 题目：**烟幕干扰弹的投放策略**

本仓库用于从零独立完成 2025 年高教社杯全国大学生数学建模竞赛 A 题。

## 资料隔离原则

本项目只允许使用：

1. 2025 国赛 A 题题面；
2. 题目官方附件/结果模板；
3. 通用数学、物理、优化与数值计算知识；
4. 后续为模型方法查阅的原始理论文献或权威方法文献。

明确禁止：

- 2025 国赛 A 题优秀论文、获奖论文、论文展示；
- 已公开的 2025 A 题完整解答、代码仓库、数值答案；
- 以他人现成模型、参数或最终数值反推本项目方案。

若检索题面时搜索结果页自动混入解题仓库/文章摘要，仅视为搜索噪声，不打开、不引用、不采用其中模型、算法、参数和最终数值；后续检索执行题面来源白名单。
