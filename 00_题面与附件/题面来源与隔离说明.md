# 题面来源与隔离说明

## 1. 本项目使用的题面来源

### 1.1 赛题发布信息

- 全国大学生数学建模竞赛官方网站：<https://www.mcm.edu.cn/>
- 2025 年赛题发布信息镜像页（来源标注 CUMCM）：<https://www.cmathc.org.cn/mcm/st/301.html>

### 1.2 只含历年题目与附件的静态归档

- CosmicLinks/cumcm-problems：<https://github.com/CosmicLinks/cumcm-problems>
- 2025 A 题目录：<https://github.com/CosmicLinks/cumcm-problems/tree/main/cumcm2025/cumcm2025a>
- A 题 PDF：<https://github.com/CosmicLinks/cumcm-problems/blob/main/cumcm2025/cumcm2025a/A%E9%A2%98.pdf>
- 附件目录：<https://github.com/CosmicLinks/cumcm-problems/tree/main/cumcm2025/cumcm2025a/%E9%99%84%E4%BB%B6>

该归档仓库 README 明确说明其为静态赛题资料库，不包含答题代码或论文；2025 A 目录中只有 `A题.pdf` 与附件目录，附件目录内为 `result1.xlsx`、`result2.xlsx`、`result3.xlsx` 三个结果模板。

### 1.3 题面纯文本复核页

- <https://xiyu2005.github.io/%E6%95%B0%E5%AD%A6%E5%BB%BA%E6%A8%A1/2025A/%E9%A2%98%E7%9B%AE>

该页面仅用于核对题面文字与坐标、速度、时间等基础输入，不作为解题来源。

## 2. 官方附件清单

2025 A 题附件共 3 个 Excel 结果模板：

1. `result1.xlsx`：问题 3 输出模板；
2. `result2.xlsx`：问题 4 输出模板；
3. `result3.xlsx`：问题 5 输出模板。

当前 GitHub 连接器只能直接创建 UTF-8 文本文件，不能把外部二进制 PDF/XLSX 直接写入本仓库，因此本阶段先保留经过核验的原始下载入口；后续若运行环境取得二进制文件，将原样放入本目录，不改动官方模板结构。

## 3. 严格隔离规则

本项目禁止读取或借鉴：

- 中国大学生在线 2025 A 题论文展示；
- 2025 A 题公开优秀论文、国奖论文；
- 任何带有完整解题、程序、最终数值答案的 GitHub 仓库、博客、课程资料；
- 搜索引擎自动给出的他人最终遮蔽时长、最优参数等结论。

题面检索过程中，搜索结果页可能自动混入解题仓库摘要。此类内容一律视为污染源：不打开、不引用、不写入模型依据，不使用其中数值校准本项目。

## 4. 阶段 01 的信息边界

阶段 01 只允许完成：

- 题面事实抽取；
- 五问任务拆解；
- 输入/输出/约束/问题依赖识别；
- 题型判断与难点清单；
- 建模风险、歧义与后续验证要求；
- 总体技术路线规划。

阶段 01 **不求最终数值，不定最终算法，不调参数，不运行正式求解代码**。
